# Whisperrr - AI-Powered Audio Transcription Platform

> **Deprecated:** This monorepo is no longer maintained. Development continues in three separate repositories:
>
> - [whisperrr-frontend](https://github.com/Shangmin-Chen/whisperrr-frontend) — React (TypeScript) UI  
> - [whisperrr-backend](https://github.com/Shangmin-Chen/whisperrr-backend) — Spring Boot API  
> - [whisperrr-py-microservice](https://github.com/Shangmin-Chen/whisperrr-py-microservice) — FastAPI + Faster Whisper  
>
> Use those repos for issues, pull requests, and local setup. The content below describes this layout for archival reference only.

A full-stack audio transcription platform using Faster Whisper (CTranslate2). Upload audio and get searchable text with segment timestamps—no database required.

## Architecture

```
┌─────────────────┐    ┌─────────────────┐    ┌─────────────┐
│  React Frontend │◄──►│ Spring Boot API │◄──►│   Python    │
│   (Port 3737)   │    │   (Port 7331)   │    │  Service    │
│                 │    │                 │    │ (Port 5001) │
└─────────────────┘    └─────────────────┘    └─────────────┘
```

- **React frontend** (`frontend/`): UI and uploads  
- **Spring Boot API** (`backend/`): Validation, proxy to Python  
- **FastAPI service** (`python-service/`): Faster Whisper transcription  

## Prerequisites

- **Java JDK 21** and Maven (or use `backend/mvnw`)  
- **Python 3.12**, FFmpeg  
- **Node.js 18+** and npm  

## Local development (no Docker)

Run each service in its own terminal from this repository root.

**1. Python service**

```bash
cd python-service
python3 -m venv venv
source venv/bin/activate   # Windows: venv\Scripts\activate
pip install -r requirements.txt
python3 -m uvicorn app.main:app --host 0.0.0.0 --port 5001
```

**2. Backend**

```bash
cd backend
./mvnw spring-boot:run
```

**3. Frontend**

```bash
cd frontend
npm install
npm start
```

Default URLs:

- Frontend: http://localhost:3737  
- Backend API: http://localhost:7331/api/audio/health  
- Python: http://localhost:5001/health  

### Remote hosts or custom ports

From the repository root:

```bash
./setup-env.sh
```

This writes `frontend/.env`, `backend/.env`, and `python-service/.env`. Restart each service after changes.

### Production-style frontend

```bash
cd frontend
npm run build
npx serve -s build -l 3737
```

## API overview

| Service | Method | Path | Description |
|--------|--------|------|-------------|
| Backend | POST | `/api/audio/transcribe` | Upload and transcribe |
| Backend | GET | `/api/audio/health` | Health |
| Python | POST | `/transcribe` | Direct transcription |
| Python | GET | `/health` | Health |

Example:

```bash
curl -X POST http://localhost:7331/api/audio/transcribe -F "audioFile=@recording.mp3"
```

## Troubleshooting

- **Python / model download**: Needs network on first run (Hugging Face).  
- **Python version**: Use `python3 --version` → 3.12.x  
- **FFmpeg**: Required by the Python service (`ffmpeg -version`).  
- **Backend port**: Change `server.port` in `backend/src/main/resources/application.properties`.  
- **Frontend API URL**: Use `./setup-env.sh` or `frontend/.env` with `REACT_APP_API_URL`; restart `npm start` after edits.  
- **CORS**: Align origins in backend (`cors.allowed-origins`) and Python (`CORS_ORIGINS`).
